# project-init 참조 문서

이 스킬의 **정본 참조 문서**는 저장소의 [`docs/project-init.md`](../../../../docs/project-init.md)다.
전체 그림·각 단계의 근거·명령 상세·폴더 구조·개발 방법론은 그 문서를 따른다.

SKILL.md는 그 문서를 8단계 플레이북 + MAY/ASK/STOP 행동 규칙으로 압축한 실행 가이드이고,
상세가 필요할 때 `docs/project-init.md`를 on-demand로 읽는다.

> 새 프로젝트에 이 스킬을 이식할 때는 `docs/project-init.md`도 함께 복사하거나,
> 이 파일의 경로를 해당 프로젝트의 문서 위치로 갱신한다.
